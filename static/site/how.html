How it works

Think of a good support desk. A junior agent reads every message, looks up the order, checks the rulebook, and only calls a senior colleague when something is unclear or risky. The router does the same with Nemotron models: Nano is the junior agent, Super and Ultra are the seniors, and plain code does anything that must be exact.

One message, step by step

    Around every call: the router layer

    These apply to every request, whether it goes through the support pipeline above or is a plain chat call from your own app.

    Confidence cascade

    For simple questions, Nano answers first and the router reads how sure it was about each word. Below a cut-off, tuned once per route on your own examples, the question goes to Super or Ultra.

    Rate-limit pacing

    Reads Token Factory's limit headers and queues requests, so customer-facing calls go before background work. Keeping usage in the 50–80% band lets your dynamic limit grow.

    Fallback

    If a model is busy or erroring, the request retries once, then moves to a sister model (Nano → Lightning, Super → Super-VL, Ultra → Super) instead of failing.

    Cost per customer

    Spend is grouped by the standard OpenAI user field. Set a budget per customer; at 90% they are moved to Nano only.

    Prompt-cache hints

    Flags dates, names or IDs at the start of a system prompt, which stop Token Factory from reusing it, and shows your cache hit rate. It suggests a fix; it never rewrites your prompt.

    LangSmith tracing

    Every Token Factory call is traced and nested under its request, so you can open one reply and see each model call, its tokens and its time. Message text is only sent with your opt-in.

    Using it from your app

    It speaks the OpenAI API. Point any OpenAI SDK at the router and use your router key.

    from openai import OpenAI
client = OpenAI(base_url="https://your-router/v1", api_key="rk-...")
client.chat.completions.create(model="support", user="customer-42",
    messages=[{"role": "user", "content": "My boots arrived torn, order 1234567890"}])
