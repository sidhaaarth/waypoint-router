Works with

OpenAI-compatible API

Same /v1/chat/completions shape, streaming included. Works with any OpenAI SDK, LangChain, LlamaIndex or plain curl: change base_url and the key.

Email or chat

The same route handles a one-off email or a back-and-forth chat. Chats get turn handling: answer the new question, then follow up on the open task.

Store connector

Shopify-shaped orders, customers and actions. The demo uses "Trailhead Outfitters", a fake store, with a live feed of every action the AI takes.

Tavily

Web search for product questions your store can't answer, limited to the brand's own site. One basic search per question.

LangSmith

Traces of every model call, grouped per request. Message text is sent only with your opt-in.

Docker / Nebius Serverless

One container image. Run it locally, in Docker Compose, or on Nebius Serverless with the database on a mounted volume. Download it.
